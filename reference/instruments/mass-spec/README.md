1. Download and extract one recording.
2. Open Module 1 or 2 and select the matching input format.
3. Import the extracted folder or file, then use Plot All to inspect the recording.

Follow the [user manual](https://ddelvalfraire.github.io/cousins-lab-tools/) for import, plotting, calibration, and results. For Python setup, see the [legacy launch guide](../../../apps/legacy/README.md).
