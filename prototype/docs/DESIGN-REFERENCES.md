# Layout editor design references

The October 2026 editor refinement uses public product screenshots shown on
[Mobbin](https://mobbin.com/). The full gallery required sign-in in the working browser.
These observations come from the public examples, rather than an authenticated gallery search.

- Fey, in the homepage's clean dashboards examples: compact headings, restrained chart
  framing, and clear separation between analytical content and tools.
- Stripe, in the multi-step forms examples: grouped fields, concise labels, and a clear
  primary action.

The editor applies those ideas through a compact page header, one save action, quieter
component cards, a fixed settings panel, and separate content and geometry sections.
Example data remains explicitly labelled. The lab's charts, scientific units, and template
model retain their existing meaning. Product screenshots are references only and are not
included in the app.
