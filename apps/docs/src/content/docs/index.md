This manual explains how to use the applications that the WSU Cousins Plant
Biology Lab uses to view and analyze mass spectrometer data.

## How this manual is versioned

Each page states which application versions it covers, in a line such as:

> **Applies to:** legacy Modules 1 and 2, spring 2026 version
> (`legacy-v0.2.0` and later).

If your copy of the application is older than the versions listed, some
buttons or steps may differ.

A new version of this manual is published each time a `docs-vX.Y.Z` release
is tagged.

## Get help

Report a problem or ask for a change on the
[project issue tracker](https://github.com/ddelvalfraire/cousins-lab-tools/issues).
