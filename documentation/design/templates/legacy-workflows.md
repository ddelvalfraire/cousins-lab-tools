# Legacy workflow coverage

Status: source findings and proposed acceptance. Every source link pins a commit. Source anomalies below are not runtime reproductions or approved scientific rules.

Legacy baseline is 9d6a7ef682c9a323170b107d54cdc2c18de0c6a8. The acquisition prototype is 722daeeb5fc32f664d86fd2fbf94833a5421e29b. The desktop scaffold is e5a4de9cb0ea5d1559acc040a6faad1155abfbce.

## Existing runtime shape

The legacy modules connect Qt buttons and plot interactions directly to handlers in mainUI/main.py. Workers reduce acquisition CSV files into plotted points. Handlers keep calibration, extracted values, and table state in the window and shared structures. Exports read those values.

The current desktop branch contains a React/Tauri greeting check, not migrated experiment workflows. [APP](https://github.com/ddelvalfraire/cousins-lab-tools/blob/e5a4de9cb0ea5d1559acc040a6faad1155abfbce/apps/desktop/src/App.tsx#L1-L57) [IPC](https://github.com/ddelvalfraire/cousins-lab-tools/blob/e5a4de9cb0ea5d1559acc040a6faad1155abfbce/apps/desktop/src-tauri/src/lib.rs#L1-L14)

The prototype has a declarative layout, template validation, revisioned files, session storage, grouped operations, calculation logic, and generated capture screens. It is a reference implementation, not a completed integration with the desktop scaffold. [PLAYOUT](https://github.com/ddelvalfraire/cousins-lab-tools/blob/722daeeb5fc32f664d86fd2fbf94833a5421e29b/prototype/core/src/layout.rs#L17-L173) [PAPI](https://github.com/ddelvalfraire/cousins-lab-tools/blob/722daeeb5fc32f664d86fd2fbf94833a5421e29b/prototype/core/src/api.rs#L180-L278)

## Proposed parity scenarios

1. Load one fixed recording through replay, full display, and different batch sizes. Derived points and range readings agree within approved tolerances.
2. Capture calibration points from intervals and enter approved manual alternatives. Each chart and metric reports consistent parameters and provenance.
3. Change a permitted analysis parameter over recorded data. The raw data hashes remain unchanged. All affected widgets converge on the same analysis revision.
4. Commit a measurement row, change calibration, and reopen the session. The row retains its original values and input context.
5. Select the final sample, an empty interval, equal endpoints, and invalid or missing signals. No invalid value enters the results table.
6. Save/import an old template revision, change the local library/profile, and reopen an existing session. The session retains its pinned screen and meaning.
7. Run mass-spec and Ambit fixtures together with a pending delayed start, failure, and Stop. Control outcomes identify the affected role and distinguish replay from hardware.
8. Export original data, reduced points, calibration, and measurement tables. Each output identifies its content, units and provenance.

Mockups demonstrate these interactions with example values. Implementation acceptance requires the actual application, approved scientific fixtures, and separately identified acquisition/hardware evidence.
